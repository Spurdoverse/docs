Every module follows the same rules. Learn them once and the per-module pages only list what's
different.

## Errors

| Situation | Result |
|:----------|:-------|
| Wrong type, missing argument, unknown option value, event name or enum string | `TypeError`, thrown right away |
| Number out of range (`NaN` where an integer is needed, negative size, bad index) | `RangeError` |
| Operation failed (I/O, sandbox, stale handle, unreadable memory, wrong phase) | `Error` with a `code`. Async calls reject with it. |

Messages name the call and the argument: `render.line: argument 3 (color) must be ColorLike`.

| Code | Meaning |
|:-----|:--------|
| `ENOENT` | Not found: file, module, DLL, export |
| `EACCES` | Access denied |
| `EEXIST` | Already exists: file, or a ui control on a taken path |
| `EIO` | I/O failure, corrupt stored value |
| `ENOSPC` | Storage full |
| `ESANDBOX` | Path outside the script's folders without the [`filesystem`](/api/manifest#permissions) permission |
| `EPERM` | Missing permission, e.g. importing `@native/ffi` without `ffi` |
| `ESTALE` | Action on a disposed handle or a dead entity |
| `EREAD` | Game memory couldn't be read |
| `EPHASE` | `render.*` draw call outside `render` |
| `EFAULT` | Native fault inside an FFI call, or an unreadable host pointer |
| `ELIBBAD` | A DLL failed to load |
| `ETHREAD` | FFI callback invoked from a foreign thread |
| `ESTATE` | WASI instance started twice |
| `EEXIT` | WASI program called `proc_exit` |
| `ECRYPTO` | WebCrypto failure |
| `ENETWORK`, `ETIMEDOUT`, `ECERT`, `EDECODE`, `EABORT` | Network transports |

[fs](/api/fs) also uses the usual Node codes (`EINVAL`, `EISDIR`, `ENOTDIR`, `ENOTEMPTY`, `EBUSY`).

```ts
import fs from "@native/fs";

try {
    fs.readFileSync("config.json", "utf8");
} catch (e) {
    if ((e as { code?: string }).code !== "ENOENT") throw e;
}
```

Exceptions thrown by your callbacks (listeners, timers, ui handlers, ESP evaluators) go to the
global [`error` event](/api/globals#errors) and the log.

## null and undefined

| Case | Result |
|:-----|:-------|
| Not found or not available: lookup miss, no map loaded, missing convar, entity gone | `null`. Never `undefined`, `0`, `""` or `false`. |
| A check that can't run (visibility with no map) | `null` |
| An action the game can refuse (input injection) | `boolean` |
| Optional parameter or option key set to `undefined` | Same as leaving it out |
| `null` passed as an argument | A value. Means "omitted" only where the signature says `\| null`. |

Numbers and strings are strict: `"5"` is not a number. Unknown option keys are ignored.

## Value types

Inputs take a Like-type, outputs are always the class.

| Type | Accepts | Returns |
|:-----|:--------|:--------|
| `Vec2Like` | `Vector2`, `Vector` (x, y), `[x, y]`, `{ x, y }` | [Vector2](/api/types/vector2) |
| `Vec3Like` | `Vector`, `[x, y, z]`, `{ x, y, z }` | [Vector](/api/types/vector) |
| `AngleLike` | `QAngle`, `[pitch, yaw, roll?]`, `{ pitch, yaw, roll? }` | [QAngle](/api/types/qangle) |
| `QuatLike` | `Quaternion`, `[x, y, z, w?]`, `{ x, y, z, w? }` | [Quaternion](/api/types/quaternion) |
| `ColorLike` | `Color`, `0xAABBGGRR`, `"#rgb"`, `"#rgba"`, `"#rrggbb"`, `"#rrggbbaa"`, `[r, g, b, a?]`, `{ r, g, b, a? }` | [Color](/api/types/color) |
| `BufferSource` | `ArrayBuffer`, any typed array, `DataView` | `Uint8Array` |
| `EntityRef` | Entity object or entity index | Entity object |
| `PointerLike` | `Pointer`, `bigint`, safe-integer `number`, `"0x…"` | [Pointer](/api/types/pointer) |

| Rule | |
|:-----|:-|
| Components | Finite numbers. Missing optional ones default: `roll` 0, `w` 1, `a` 255. |
| Colors | Channels 0–255, clamped and rounded. |
| Angles | Degrees, everywhere. |
| 64-bit integers | `bigint`. Inputs also take a safe-integer `number`. |
| Rectangles | 2D: `{ min: Vector2, max: Vector2 }`. 3D boxes: `{ mins: Vector, maxs: Vector }`. |

```ts
import render from "@native/render";

on("render", () => {
    render.line([0, 0], new Vector2(100, 100), "#ff4040");
    render.circle({ x: 200, y: 200 }, 20, [255, 255, 255, 128]);
});
```

## Handles

Objects the script creates and owns (ESP elements, ui controls, signals, FFI libraries and
callbacks, `WASI`) share one shape.

| Member | |
|:-------|:-|
| `alive` | `false` once disposed |
| `dispose()` | Releases it. Idempotent. |
| `[Symbol.dispose]` | Same, so `using` works |

After disposal, reads return `null` and writes or actions throw `ESTALE`. A handle never re-binds
to something new. Entities work the same way: once the entity is destroyed `alive` is `false`
and its fields return `null`.

Everything a script owns is released when it unloads, so `dispose()` is only for removing
something early.

```ts
import ffi from "@native/ffi";

function tickCount(): number {
    using k32 = ffi.open("kernel32.dll");
    return k32.func<() => number>("DWORD GetTickCount(void)")();
} // k32 disposed here
```

<Warning>
  `using` at the top level of a module disposes as soon as the module finishes loading. Keep
  long-lived handles in a plain `const`.
</Warning>

## Phases

| | `tick` | `render` |
|:-|:-------|:---------|
| Rate | 128 Hz, fixed | Once per overlay frame |
| For | Logic, reading entities, input | Draw calls |
| `render.*` draw calls | Throw `EPHASE` | Work, synchronously only |
| `render.worldToScreen`, `render.boundsOf` | Tick camera | This frame's camera |

Entity, game, convar and input data is refreshed right before each tick. Draw calls also throw
`EPHASE` at the top level, in timers and after an `await` inside `render`. ESP `evaluate`
callbacks run on the tick.

## Address spaces

| Space | Type | Where |
|:------|:-----|:------|
| Game process | [Pointer](/api/types/pointer) | [memory](/api/memory), `entity.address`, `Pointer.read("ptr")` |
| Host process | `bigint`, `null` for NULL | [ffi](/api/ffi) |

The two never mix. A `Pointer` passed to an FFI function becomes its integer value, which is what
`ReadProcessMemory` wants.
