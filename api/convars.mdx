Reads engine console variables by exact name.

```ts
import convars from "@native/convars";
```

<Note>
  Values are read at most once per tick. A convar that doesn't exist is `null` and is looked up again
  later, so one registered after your first try is still found.
</Note>

---

## Reading

{/* ------------------------------------------------------------------ */}

### get

<br />

```ts
convars.get(name: string): ConvarValue | null
```

The value in its natural type, or `null` when the convar doesn't exist.

| Convar type | Value |
|:------------|:------|
| `bool` | `boolean` |
| `int16` `uint16` `int32` `uint32` `float32` `float64` | `number` |
| `int64` `uint64` | `bigint` |
| `string` | `string` |
| `color` | [Color](/api/types/color) |
| `vector2`, `vector3`, `qangle` | [Vector2](/api/types/vector2), [Vector](/api/types/vector), [QAngle](/api/types/qangle) |
| `vector4` | `[x, y, z, w]` |

```ts
const cheats = convars.get("sv_cheats");   // boolean | null
```

{/* ------------------------------------------------------------------ */}

### typeOf

<br />

```ts
convars.typeOf(name: string): ConvarType | null
```

The convar's engine type from the table above, or `null` when it doesn't exist.

```ts
convars.typeOf("sensitivity");   // "float32"
```

{/* ------------------------------------------------------------------ */}

### Typed getters

<br />

```ts
convars.getBool(name: string): boolean | null
convars.getInt(name: string): number | null
convars.getFloat(name: string): number | null
convars.getString(name: string): string | null
```

Convert by the convar's real type. `null` when it doesn't exist, `TypeError` when its type can't convert (`getFloat` on a string convar).

| Getter | Accepts |
|:-------|:--------|
| `getBool` | bool, integers, floats (`!= 0`) |
| `getInt` | bool (0/1), integers, floats (toward zero); `RangeError` beyond ±2^53 |
| `getFloat` | bool (0/1), integers, floats |
| `getString` | string |

```ts
const sens = convars.getFloat("sensitivity") ?? 1;
const yaw = convars.getFloat("m_yaw") ?? 0.022;
const degreesPerCount = sens * yaw;
```

## Example

Mouse counts needed to turn a given angle, for input code that moves the mouse.

```ts
import convars from "@native/convars";

function countsFor(degrees: number): number | null {
    const sens = convars.getFloat("sensitivity");
    const yaw = convars.getFloat("m_yaw");
    if (sens === null || yaw === null || sens === 0) return null;
    return Math.round(degrees / (sens * yaw));
}

on("keydown", (e) => {
    if (e.code !== "F8") return;
    console.log("180° =", countsFor(180), "counts");
    console.log("zoom ratio:", convars.getFloat("zoom_sensitivity_ratio"));
});
```
