`wasi_snapshot_preview1` for WebAssembly modules, shaped like Node's `node:wasi`. `WebAssembly` itself is
the standard global ([MDN](https://developer.mozilla.org/en-US/docs/WebAssembly/Reference/JavaScript_interface)).

```ts
import { WASI } from "@native/wasi";
```

<Note>
  Nothing is patched globally. Create a `WASI`, pass its imports to `WebAssembly.instantiate`, then
  `start()` a command or `initialize()` a reactor.
</Note>

---

## WASI

{/* ------------------------------------------------------------------ */}

### constructor

<br />

```ts
new WASI(options?: WASIOptions)
```

Creates one WASI environment. Throws `TypeError` for malformed options, `RangeError` for more than 4096
args/env entries or more than 1 MiB of them, and `EPERM` / `ENOENT` for a bad preopen.

| Option | Default | |
|:-------|:--------|:--|
| `args` | `[]` | argv, including `argv[0]` |
| `env` | `{}` | environment variables |
| `preopens` | `{ "/": data/ }` | guest directory → host directory; relative host paths start at `data/` |
| `returnOnExit` | `true` | `proc_exit(code)` ends `start()`, which returns `code`; `false` makes `start()` throw instead |
| `version` | `"preview1"` | the only one |

A host directory outside `data/` needs the `filesystem` [permission](/api/manifest#permissions)
(`EPERM` otherwise) and must exist (`ENOENT`).

```ts
const wasi = new WASI({
    args: ["app", "--fast"],
    env: { MODE: "demo" },
    preopens: { "/": ".", "/assets": "assets" },
});
```

{/* ------------------------------------------------------------------ */}

### getImportObject

<br />

```ts
wasi.getImportObject(): { wasi_snapshot_preview1: Readonly<Record<string, WasiSyscall>> }
```

The imports to pass to `WebAssembly.instantiate`. `wasi.wasiImport` is the same syscall table on its own,
for merging with your own imports.

```ts
const { instance } = await WebAssembly.instantiate(bytes, wasi.getImportObject());

const imports = { wasi_snapshot_preview1: wasi.wasiImport, env: { log: (n: number) => console.log(n) } };
```

{/* ------------------------------------------------------------------ */}

### start

<br />

```ts
wasi.start(instance: WebAssembly.Instance): number
```

Runs a command: calls `_start()` and returns the exit code (0 when `_start` returns). The module must
export `memory` and `_start` and must not export `_initialize` (`TypeError`). Only one `start()` or
`initialize()` per `WASI` (`ESTATE`).

```ts
const code = wasi.start(instance);
```

With `returnOnExit: false`, `proc_exit` throws an `Error` with `code: "EEXIT"` and `exitCode`.

{/* ------------------------------------------------------------------ */}

### initialize

<br />

```ts
wasi.initialize(instance: WebAssembly.Instance): void
```

Sets up a reactor: calls `_initialize()` if it's exported. The module must export `memory` and must not
export `_start`. Then call its exports yourself.

```ts
wasi.initialize(instance);
const add = instance.exports.add as (a: number, b: number) => number;
add(2, 3);
```

{/* ------------------------------------------------------------------ */}

### dispose

<br />

```ts
wasi.dispose(): void
```

Closes every file the guest opened and releases its memory. Idempotent; runs on unload at the latest.
After it the syscalls throw `ESTALE`. `alive` is `false` from then on, and `using` disposes at the end
of the block.

## Guest environment

| | |
|:--|:--|
| argv / environ | exactly `args` / `env` |
| Filesystem | only the preopens; `..`, symlinks and drive/device names are refused with `ENOTCAPABLE` |
| stdin | empty |
| stdout / stderr | lines go to the script log, stderr at error level |
| Clocks | realtime, monotonic, process and thread CPU time |
| `poll_oneoff` | never blocks: files are always ready, and a pending clock fires at once, so `sleep()` returns immediately |
| Sockets | none; `sock_*` report `ENOTSOCK` / `EBADF` |
| Unsupported | `path_symlink` (`ENOTSUP`), `proc_raise` (`ENOSYS`) |

Every guest pointer is bounds-checked against the current memory size; a bad one is `EFAULT` for the guest.

## Example

Run a WASI command from `data/app.wasm`.

```ts
import { WASI } from "@native/wasi";
import fs from "@native/fs";

async function runApp(args: string[]): Promise<number> {
    using wasi = new WASI({ args: ["app", ...args], env: { MODE: "demo" } });
    const bytes = await fs.readFile("app.wasm");
    const { instance } = await WebAssembly.instantiate(bytes, wasi.getImportObject());
    return wasi.start(instance);
}

const code = await runApp(["--fast"]);
console.log("exit", code);
```
