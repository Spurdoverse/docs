The browser's `localStorage`, persistent across script reloads and game restarts. Global, no import.

<Note>
  Storage is per script **folder**, not `manifest.name`: two scripts never see each other's keys, even
  with the same name.
</Note>

Unlike the browser, values aren't stringified. They're stored with structured clone, so you get back
the type you stored: numbers, booleans, plain objects, arrays, `Map`, `Set`, `Date`, `RegExp`, typed
arrays, `BigInt`. Class instances come back as plain objects. Functions, symbols and native objects
(`Vector`, `Pointer`, …) throw a `DataCloneError`.

---

## Methods

{/* ------------------------------------------------------------------ */}

### getItem

<br />

```ts
localStorage.getItem<T = any>(key: string): T | null
```

A copy of the stored value, or `null` when the key doesn't exist. Throws `EIO` when the stored value is
corrupt.

```ts
const runs = localStorage.getItem<number>("runs") ?? 0;
```

{/* ------------------------------------------------------------------ */}

### setItem

<br />

```ts
localStorage.setItem(key: string, value: any): void
```

Stores `value` under `key`. `undefined` removes the key, `null` is stored as a value.

```ts
localStorage.setItem("runs", runs + 1);
localStorage.setItem("seen", new Set([1, 2, 3]));
localStorage.setItem("runs", undefined);   // removed
```

{/* ------------------------------------------------------------------ */}

### Others

| Member | |
|:-------|:--|
| `removeItem(key: string): void` | deletes the key |
| `clear(): void` | deletes every key of this script |
| `key(index: number): string \| null` | the key at `index`, `null` when out of range |
| `length: number` | number of keys |

Keys must be strings; anything else is a `TypeError`, not converted.

---

## Property access

Keys work as properties too.

```ts
localStorage.config = { fov: 90 };
localStorage.config.fov;          // 90
delete localStorage.config;
Object.keys(localStorage);        // every key
localStorage.fov = undefined;     // removes "fov"
```

This doesn't work for the method names, `length` and inherited `Object.prototype` members
(`toString`, `constructor`, …). Use `getItem` / `setItem` for those keys.

---

## Errors

| Error | When |
|:------|:-----|
| `TypeError` | key isn't a string |
| `DataCloneError` | value can't be cloned |
| `RangeError` | key longer than about 500 bytes of UTF-8 (reading or removing it just finds nothing) |
| `ENOSPC` | storage is full |
| `EIO` | any other failed write, or a stored value that can't be read back |

---

## Example

Remember the last few maps played.

```ts
import game from "@native/game";

let lastMap: string | null = null;

on("tick", () => {
    const map = game.shortMapName;
    if (!map || map === lastMap) return;
    lastMap = map;

    const recent = localStorage.getItem<string[]>("recentMaps") ?? [];
    const next = [map, ...recent.filter((m) => m !== map)].slice(0, 5);
    localStorage.setItem("recentMaps", next);
    console.log("recent maps:", next.join(", "));
});
```
