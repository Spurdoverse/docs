A 3D vector: world positions, directions, velocities. Global class, no import.

```ts
const eye = new Vector(0, 0, 64);
const above = eye.add([0, 0, 16]);   // [x, y, z] and { x, y, z } work anywhere a Vector does
```

Fields are 32-bit floats; assigning a non-number or NaN throws.

## Length and distance

The `2D` variants ignore `z`, which is what you want for horizontal distance on a map.

| Method | Returns |
|:-------|:--------|
| `length()`, `lengthSqr()` | Length, squared length |
| `length2D()`, `length2DSqr()` | Same, ignoring `z` |
| `distTo(other)`, `distToSqr(other)` | Distance, squared distance |
| `distTo2D(other)` | Distance ignoring `z` |
| `dot(other)` | Dot product |
| `cross(other)` | Cross product, a new `Vector` |

```ts
const speed = velocity.length2D();              // horizontal speed, units/s
const near = myPos.distToSqr(pos) < 500 * 500;  // skips the sqrt
```

## Angles

Engine convention, in degrees: pitch positive looks down. See [QAngle](/api/types/qangle).

{/* ------------------------------------------------------------------ */}

### toAngles

<br />

```ts
toAngles(): QAngle
```

The view angles that look along this direction, roll `0`.

```ts
new Vector(0, 1, 0).toAngles();   // QAngle(0, 90, 0)
velocity.toAngles().yaw;          // direction of travel
```

{/* ------------------------------------------------------------------ */}

### angleTo

<br />

```ts
angleTo(target: Vec3Like): QAngle
```

The view angles that aim from this point at `target`. Same as `target.sub(this).toAngles()`.

```ts
const aim = eyePos.angleTo(headPos);
if (viewAngles.fovTo(aim) < 3) {
    // within 3° of the crosshair
}
```

For screen positions use [render.worldToScreen](/api/render#worldtoscreen), not angles.

## Example

Finds the enemy whose head is closest to the crosshair and circles it.

```ts
import entities from "@native/entities";
import input from "@native/input";
import render from "@native/render";

on("render", () => {
    const me = entities.getLocalPlayer();
    const eye = me?.getEyePosition();
    const view = input.state.viewAngles;
    if (!me || !eye || !view) return;

    let best: Vector | null = null;
    let bestFov = 10;
    for (const enemy of entities.getPlayers({ skipLocal: true })) {
        if (!enemy.isEnemy(me)) continue;
        const head = enemy.getBone("head_0")?.position;
        if (!head) continue;

        const fov = view.fovTo(eye.angleTo(head));
        if (fov < bestFov) { bestFov = fov; best = head; }
    }

    const screen = best && render.worldToScreen(best);
    if (screen) render.circle(screen, 8, "#ff4040");
});
```
