View angles in degrees, engine convention. Global class, no import.

```ts
const down = new QAngle(89, 0);            // roll defaults to 0
const aim = view.add([0, 45]);             // [pitch, yaw, roll?] and { pitch, yaw, roll? } work too
```

<Note>
  Pitch positive looks down, yaw turns counter-clockwise from +X, roll spins around the view direction.
  Fields `pitch`, `yaw`, `roll` are 32-bit floats. Assigning a non-number throws `TypeError`, NaN, Infinity or a value beyond float range throws `RangeError`.
</Note>

## Common

<ValueClassCommon name="QAngle" like="AngleLike" />

`clamp()` changes the value too. `equals` compares raw components without wrapping, so normalize both sides first.

| Also | Returns |
|:-----|:--------|
| `QAngle.zero()` | `(0, 0, 0)` |
| `negate()` | New `QAngle` |
| `isFinite()` | No NaN or infinite component |

{/* ------------------------------------------------------------------ */}

### lerp

<br />

```ts
lerp(other: AngleLike, t: number): QAngle
```

Blends each component along the shorter arc, so `170 → -170` passes through `180`, not `0`. `t` isn't clamped and the result isn't wrapped.

```ts
const smoothed = view.lerp(aim, 0.2).clamped();   // aim smoothing
```

## Wrapping

{/* ------------------------------------------------------------------ */}

### normalize

<br />

```ts
normalize(): this
normalized(): QAngle
```

Wraps every component into `[-180, 180]`. `normalize()` changes the angle, `normalized()` returns a copy.

```ts
new QAngle(0, 270).normalized();   // QAngle(0, -90, 0)
```

{/* ------------------------------------------------------------------ */}

### clamp

<br />

```ts
clamp(): this
clamped(): QAngle
```

Makes it a valid view angle: pitch wrapped then clamped to `[-89, 89]`, yaw wrapped into `[-180, 180]`, roll `0`. `clamp()` changes the angle, `clamped()` returns a copy.

```ts
new QAngle(120, 200, 5).clamped();   // QAngle(89, -160, 0)
```

<Warning>
  Clamp anything you compute before using it as view angles. `add`, `sub` and `lerp` don't wrap.
</Warning>

## Direction

{/* ------------------------------------------------------------------ */}

### forward

<br />

```ts
forward(): Vector
right(): Vector
up(): Vector
```

Unit vectors of the view. `forward()` is where the crosshair points.

```ts
const end = eye.add(view.forward().scale(8192));   // a point straight ahead
```

{/* ------------------------------------------------------------------ */}

### fovTo

<br />

```ts
fovTo(other: AngleLike): number
```

The real angle between the two view directions, `0`–`180` degrees. This is the aimbot "FOV" to a target.

```ts
if (view.fovTo(eye.angleTo(headPos)) < 5) {
    // within 5° of the crosshair
}
```

Get the target angles with [Vector.angleTo](/api/types/vector#angleto).

{/* ------------------------------------------------------------------ */}

### toQuaternion

<br />

```ts
toQuaternion(): Quaternion
```

The same rotation as a [Quaternion](/api/types/quaternion).

```ts
const q = view.toQuaternion();
q.rotate([1, 0, 0]);   // same as view.forward()
```

## Example

Lists enemies by how far left or right of your view they are.

```ts
import entities from "@native/entities";
import input from "@native/input";
import render from "@native/render";

on("render", () => {
    const me = entities.getLocalPlayer();
    const eye = me?.getEyePosition();
    const view = input.state.viewAngles;
    if (!me || !eye || !view) return;

    let y = 100;
    for (const enemy of entities.getPlayers({ skipLocal: true })) {
        const pos = enemy.isEnemy(me) ? enemy.getOrigin() : null;
        if (!pos) continue;

        // sub() doesn't wrap: 179 - (-179) is 358 until normalized
        const delta = eye.angleTo(pos).sub(view).normalized();
        const side = delta.yaw > 0 ? "left" : "right";

        render.text([render.screenSize.x / 2, y], `${Math.abs(delta.yaw).toFixed(0)}° ${side}`, "#ffffff");
        y += 16;
    }
});
```
