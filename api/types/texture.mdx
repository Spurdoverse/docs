An image the overlay can draw with [render.image](/api/render#image). Global class, no import.

```ts
const logo = new Texture("assets/logo.png");
```

<Note>
  Loading and the GPU upload happen in the background. `width` and `height` are `0` until `ready` is `true`, and `render.image` draws nothing before that.
</Note>

---

## Loading

{/* ------------------------------------------------------------------ */}

### constructor

<br />

```ts
new Texture(path: string, options?: { width?: number; height?: number })
```

Loads a PNG, JPG, BMP, TGA, GIF (first frame) or SVG. `path` is relative to the script folder. A missing file throws `Error` with code `ENOENT`. Textures are cached by resolved path, so loading the same file twice is cheap.

```ts
const icon = new Texture("icons/bomb.png");
const logo = new Texture("assets/logo.svg", { width: 64 });   // height keeps the aspect ratio
```

`width` and `height` (`1`–`8192`) only apply to SVG and set its raster size. By default it's 4× the SVG's own size.

<Warning>
  Without the `filesystem` [permission](/api/manifest#permissions) the file must be inside the script folder. Absolute paths, `..` and symlinks that lead out of it throw `Error` with code `ESANDBOX`.
</Warning>

{/* ------------------------------------------------------------------ */}

### fromMemory

<br />

```ts
Texture.fromMemory(data: BufferSource, width: number, height: number): Texture
```

A texture from raw RGBA8 pixels: row-major, 4 bytes per pixel, no row padding. The pixels are copied, so you can reuse `data`.

| Throws | When |
|:-------|:-----|
| `RangeError` | `width` or `height` outside `1`–`8192`, or `data` shorter than `width * height * 4` bytes |
| `TypeError` | `data` is a detached buffer |

```ts
const size = 32;
const pixels = new Uint8Array(size * size * 4);
for (let i = 0; i < size * size; i++) {
    const x = i % size;
    pixels.set([255, 255, 255, Math.round((x / (size - 1)) * 255)], i * 4);   // white, fading in
}
const gradient = Texture.fromMemory(pixels, size, size);
```

---

## Properties

| Property | Type | |
|:---------|:-----|:--|
| `ready` | `boolean` | `true` once uploaded. Stays `false` if the file couldn't be decoded. |
| `width`, `height` | `number` | Size in pixels, `0` until `ready` |
| `path` | `string` or `null` | The resolved file path, `null` for `fromMemory` textures |

`toString()` gives something like `Texture(64x64, ready, "C:/…/logo.svg")`.

---

## Example

A logo in the top-right corner at its real size, once it has loaded.

```ts
import render from "@native/render";

const logo = new Texture("assets/logo.svg", { height: 48 });

on("render", () => {
    if (!logo.ready) return;

    const max = new Vector2(render.screenSize.x - 16, 16 + logo.height);
    const min = max.sub([logo.width, logo.height]);
    render.image(logo, min, max, { tint: Color.white().withAlphaF(0.8), rounding: 6 });
});
```
