Scripts run in a context shaped like a Web Worker. The APIs below are globals and follow the specs, so
[MDN](https://developer.mozilla.org/en-US/docs/Web/API) is the reference. This page only lists what's
there and where it differs.

<Note>
  There's no `window`, `document`, `sessionStorage`, `indexedDB`, `Worker`, `alert`/`prompt` or
  `onmessage`. TypeScript's DOM types still declare them, but at runtime they don't exist. `self` and
  `globalThis` do. `Symbol.dispose` exists (`using` works); `DisposableStack` and `SuppressedError` don't.
</Note>

## What's there

| Area | Globals |
|:-----|:--------|
| Networking | `fetch`, `Headers`, `Request`, `Response`, `FormData`, `XMLHttpRequest`, `WebSocket`, `EventSource`: see [Networking](/api/networking) |
| Events | `EventTarget`, `Event`, `CustomEvent`, `ErrorEvent`, `MessageEvent`, `PromiseRejectionEvent`, `KeyboardEvent`, `MouseEvent`, `WheelEvent`, `AbortController`, `AbortSignal`, `DOMException` |
| Text | `TextEncoder`, `TextDecoder`, `btoa`, `atob`, `URL`, `URLSearchParams` |
| Binary | `Blob`, `File`, `FileReader`, `URL.createObjectURL`, `structuredClone` |
| Streams | `ReadableStream`, `WritableStream`, `TransformStream`, queuing strategies, `TextEncoderStream`, `TextDecoderStream`, `CompressionStream`, `DecompressionStream` |
| Crypto | `crypto.getRandomValues`, `crypto.randomUUID`, `crypto.subtle` |
| Scheduling | `queueMicrotask`, `requestAnimationFrame`, `requestIdleCallback`, `MessageChannel`, `performance`, `reportError` |
| Other | `navigator`, `origin`, `WebAssembly` (with [WASI](/api/wasi)) |

Timers, `console` and the host events are on [Globals](/api/globals), storage on
[localStorage](/api/localStorage).

## Differences

| API | Here |
|:----|:-----|
| `URL` | no IDNA/punycode, non-ASCII host names aren't converted |
| `TextDecoder` | only `utf-8`, `utf-16le`, `utf-16be`, `windows-1251`, `windows-1252` (also `latin1`, `ascii`) and `koi8-r`; other labels throw `RangeError` |
| `CompressionStream` | `gzip`, `deflate`, `deflate-raw` |
| `DecompressionStream` | the same plus `br` |
| `ReadableStream` | no transferable streams; a BYOB read copies into your buffer instead of filling it in place |
| `structuredClone` | the `transfer` option is ignored |
| `requestAnimationFrame`, `requestIdleCallback` | run from the `render` event, once per overlay frame |
| `performance` | `now`, `timeOrigin`, `mark`, `measure`; no entry buffer |
| `navigator` | fixed values (`platform: "Win32"`, `language: "en-US"`, …), nothing is detected |

## crypto.subtle

| Kind | Algorithms |
|:-----|:-----------|
| Digest | SHA-1, SHA-256, SHA-384, SHA-512 |
| MAC | HMAC |
| Ciphers | AES-GCM, AES-CBC, AES-CTR, RSA-OAEP |
| Signatures | RSASSA-PKCS1-v1_5, RSA-PSS, ECDSA |
| Derivation | PBKDF2, HKDF, ECDH |
| Curves | P-256, P-384, P-521 |
| Key formats | `raw`, `jwk`, `spki`, `pkcs8` |

Other algorithms (Ed25519, X25519, SHA-3, …) reject with `NotSupportedError`. `wrapKey` / `unwrapKey` go
through the ciphers above; AES-KW keys can be created but not used to wrap. AES-GCM `tagLength` must be 96,
104, 112, 120 or 128 and the `iv` 1–64 bytes. RSA `modulusLength` is 1024–8192, a multiple of 8.

<Warning>
  `crypto.subtle` runs on the script thread. Hashes, HMAC and AES are instant, but RSA `generateKey` takes
  tens of milliseconds (4096-bit far more). Generate keys once and keep them.
</Warning>

```ts
const key = await crypto.subtle.importKey(
    "raw", new TextEncoder().encode("secret"),
    { name: "HMAC", hash: "SHA-256" }, false, ["sign"]);

const mac = await crypto.subtle.sign("HMAC", key, new TextEncoder().encode("payload"));
const hex = [...new Uint8Array(mac)].map((b) => b.toString(16).padStart(2, "0")).join("");
```
