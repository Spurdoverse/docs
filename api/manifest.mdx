Every script folder has a `manifest.json`. The loader reads it first; no manifest, no script.

```json
{
    "name": "my-script",
    "author": "you",
    "version": "1.0.0",
    "description": "Enemy boxes and a health bar",
    "entry": "dist/index.js",
    "permissions": ["filesystem"]
}
```

---

## Fields

All fields are optional. The values end up on the [`script`](/api/globals#script) global.

| Field | Type | Default | |
|:------|:-----|:--------|:-|
| `name` | `string` | `"unnamed"` | Shown in the menu and the log. Two loaded scripts can't share a name. |
| `author` | `string` | `"unknown"` | |
| `version` | `string` | `"1.0.0"` | |
| `description` | `string` | `""` | |
| `entry` | `string` | `"dist/index.js"` | The module to run, relative to the folder. It can't point outside it. |
| `permissions` | `string[]` | both granted | See [below](#permissions). |

`localStorage` is keyed by the folder name, not `name`.

---

## Permissions

Two capabilities: `"filesystem"` and `"ffi"`.

| Manifest | Granted |
|:---------|:--------|
| no `permissions` key | both |
| `["filesystem", "ffi"]` | both |
| `["filesystem"]` | only `filesystem` |
| `[]` | nothing |
| an unknown name, or not an array of strings | the script doesn't load, the log lists the valid names |

| Permission | Without it | With it |
|:-----------|:-----------|:--------|
| `filesystem` | [fs](/api/fs) and [WASI](/api/wasi) are confined to the script's `data/` folder, [Texture](/api/types/texture) to the script folder. Absolute paths and `..` escapes throw `ESANDBOX`. | Any path works. |
| `ffi` | Importing [@native/ffi](/api/ffi) throws `EPERM`. | Load DLLs and call native code in the host process. |

Everything else (entities, render, esp, ui, input, memory, trace, networking, `localStorage`) needs
no permission. At runtime, `script.permissions` lists what was granted.

```ts
if (script.permissions.includes("filesystem")) console.log("full disk access");
```

## Folder layout

```
my-script/
├── manifest.json
├── src/index.ts
├── dist/index.js     <- "entry"
└── data/             <- fs and WASI root, created on first use
```

Imports resolve to `@native/*` modules and relative files inside the folder. `.js` is appended
when there's no extension. There's no `node_modules` at runtime.

The script hot-reloads when any file in its folder changes, except under `data/`.
