File I/O shaped like Node's `fs`. Every async function has a `*Sync` twin with the same behaviour; the
async ones run on a thread pool and never block the script.

```ts
import fs from "@native/fs";
```

<Note>
  Relative paths start at the script's `data/` folder (created on first import). Without the `filesystem`
  [permission](/api/manifest#permissions) everything stays inside it: an absolute path, a `..` escape or a
  link pointing out throws `ESANDBOX`. With it, absolute paths are used as given.
</Note>

Failures are thrown by the `*Sync` functions and reject the others, as an `Error` with `code`, `syscall`
and `path`. A wrong argument type is a `TypeError` thrown synchronously by both. See [Errors](#errors).

## Reading and writing

{/* ------------------------------------------------------------------ */}

### readFile

<br />

```ts
fs.readFile(path: string, options?: BufferEncoding | { encoding?: BufferEncoding | null } | null): Promise<string | Uint8Array>
fs.readFileSync(path: string, options?: ...): string | Uint8Array
```

Reads a whole file: a `Uint8Array` without an encoding, a string with one. Files over 1 GiB throw a
`RangeError` with code `ERR_FS_FILE_TOO_LARGE`.

```ts
const raw = await fs.readFile("icon.png");                 // Uint8Array
const config = JSON.parse(fs.readFileSync("config.json", "utf8"));
```

Encodings (case-insensitive): `utf8`, `latin1` (`binary`), `ascii`, `hex`, `base64`, `base64url`,
`utf16le` (`ucs2`).

{/* ------------------------------------------------------------------ */}

### writeFile

<br />

```ts
fs.writeFile(path: string, data: string | BufferSource, options?: BufferEncoding | { encoding?: BufferEncoding | null } | null): Promise<void>
fs.writeFileSync(path, data, options?): void
```

Creates or replaces a file. Strings are encoded as UTF-8 unless you pass an encoding; the encoding is
ignored for binary data.

```ts
await fs.writeFile("output.txt", "Hello, world!");
fs.writeFileSync("dump.bin", new Uint8Array([1, 2, 3]));
fs.writeFileSync("key.bin", "deadbeef", "hex");
```

{/* ------------------------------------------------------------------ */}

### appendFile

<br />

```ts
fs.appendFile(path: string, data: string | BufferSource, options?): Promise<void>
fs.appendFileSync(path, data, options?): void
```

Same as `writeFile`, but appends, and creates the file when it doesn't exist.

```ts
fs.appendFileSync("kills.log", `${new Date().toISOString()} kill\n`);
```

## Files and directories

{/* ------------------------------------------------------------------ */}

### exists

<br />

```ts
fs.exists(path: string): Promise<boolean>
fs.existsSync(path: string): boolean
```

`true` when something exists at `path`. A path outside the sandbox still throws `ESANDBOX`.

```ts
if (!fs.existsSync("config.json")) fs.writeFileSync("config.json", "{}");
```

{/* ------------------------------------------------------------------ */}

### stat

<br />

```ts
fs.stat(path: string): Promise<Stats>
fs.statSync(path: string): Stats
```

Follows symbolic links. Throws `ENOENT` when nothing is there.

```ts
const st = fs.statSync("config.json");
console.log(st.size, new Date(st.mtimeMs), st.isFile());
```

| `Stats` member | |
|:---------------|:--|
| `size` | bytes, `0` for directories |
| `atimeMs`, `mtimeMs`, `birthtimeMs` | ms since the Unix epoch |
| `isFile()`, `isDirectory()` | |
| `isSymbolicLink()` | always `false`, links are followed |

{/* ------------------------------------------------------------------ */}

### mkdir

<br />

```ts
fs.mkdir(path: string, options?: { recursive?: boolean }): Promise<void>
fs.mkdirSync(path, options?): void
```

Throws `EEXIST` when the directory exists and `ENOENT` when the parent is missing. With `recursive`
it creates the parents and succeeds when the directory is already there.

```ts
await fs.mkdir("saves/p1", { recursive: true });
```

{/* ------------------------------------------------------------------ */}

### rmdir

<br />

```ts
fs.rmdir(path: string, options?: { recursive?: boolean }): Promise<void>
fs.rmdirSync(path, options?): void
```

Removes a directory: `ENOENT` when missing, `ENOTDIR` for a file, `ENOTEMPTY` when it has entries
and `recursive` isn't set. Without `filesystem`, `data/` itself can't be removed (`ESANDBOX`).

```ts
fs.rmdirSync("cache", { recursive: true });
```

{/* ------------------------------------------------------------------ */}

### Other operations

| Function | |
|:---------|:--|
| `readdir(path): Promise<string[]>` | entry names (not paths), without `.` and `..` |
| `unlink(path): Promise<void>` | deletes a file; `ENOENT` when missing, `EISDIR` for a directory |
| `rename(oldPath, newPath): Promise<void>` | moves or renames, replacing an existing file |
| `copyFile(src, dest): Promise<void>` | copies a file, replacing an existing one |
| `truncate(path, length = 0): Promise<void>` | shrinks or zero-extends to `length` bytes |

Each has a `*Sync` twin.

```ts
for (const name of await fs.readdir("saves"))
    if (fs.path.extname(name) === ".tmp") await fs.unlink(fs.path.join("saves", name));
```

## Watching

{/* ------------------------------------------------------------------ */}

### watch

<br />

```ts
fs.watch(path: string, listener: (eventType: "rename" | "change", filename: string | null) => void,
         options?: { recursive?: boolean; signal?: AbortSignal }): FSWatcher
```

Calls `listener` for every change: `"rename"` for created, deleted or renamed entries, `"change"` for
modified ones. `filename` is relative to the watched path, or `null` when the OS didn't report one.
Throws (`ENOENT`, …) when the path can't be watched.

```ts
const watcher = fs.watch("configs", (event, name) => console.log(event, name), { recursive: true });
watcher.close();
```

A listener that throws is reported like any uncaught error and the watcher keeps running. An error in
the watcher itself closes it and is reported the same way. Watchers close when the script unloads;
`close()`, `using` or an aborted `signal` close them earlier.

## Paths

`fs.path` is Node's `path` (Windows flavour) for the common helpers. Pure string work: no I/O, no
sandbox check.

| Function | Example |
|:---------|:--------|
| `join(...paths)` | `join("saves", "p1", "../p2", "a.json")` → `"saves\\p2\\a.json"` |
| `basename(path, suffix?)` | `basename("saves/p1/a.json", ".json")` → `"a"` |
| `dirname(path)` | `dirname("saves/p1/a.json")` → `"saves/p1"` |
| `extname(path)` | `extname("a.json")` → `".json"`, `extname(".bashrc")` → `""` |
| `isAbsolute(path)` | `true` for `"C:\\x"`, `"\\x"`, `"\\\\server\\share"`; `false` for `"C:x"` |

## Errors

| Property | |
|:---------|:--|
| `code` | `ENOENT`, `EEXIST`, `EISDIR`, `ENOTDIR`, `ENOTEMPTY`, `EACCES`, `EBUSY`, `ESANDBOX`, … |
| `syscall` | the failed operation (`"open"`, `"mkdir"`, …); absent for `ESANDBOX` |
| `path` | the path as you passed it |
| `dest` | the second path of `rename` / `copyFile` |

```ts
try {
    fs.readFileSync("missing.json", "utf8");
} catch (e) {
    if ((e as { code?: string }).code !== "ENOENT") throw e;
}
```

## Example

A JSON settings file that reloads when you edit it.

```ts
import fs from "@native/fs";

type Settings = { fov: number; color: string };
const defaults: Settings = { fov: 90, color: "#ff4040" };
let settings = defaults;

function load(): void {
    try {
        settings = { ...defaults, ...JSON.parse(fs.readFileSync("settings.json", "utf8")) };
    } catch (e) {
        if ((e as { code?: string }).code === "ENOENT")
            fs.writeFileSync("settings.json", JSON.stringify(defaults, null, 2));
        else
            console.warn("settings.json:", e);
    }
}

load();
fs.watch(".", (event, name) => {
    if (name === "settings.json") load();
});

on("tick", () => { /* use settings.fov, settings.color */ });
```
